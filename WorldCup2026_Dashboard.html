Learning Algorithm — Technical Details

📐 Brier Score
BS = (1/N) Σ Σ (p_ij − o_ij)² where p = predicted prob, o = actual outcome (0/1). Range: 0 (perfect) to 2 (worst). Good calibration: BS < 0.25.
⚡ Gradient Descent
w_i ← w_i + α · (correct ? +contribution_i : −contribution_i). Learning rate α = 0.05. Applied per match, weights re-normalized to Σw = 100 after each step.
📊 Factor Attribution
Each factor score (0-100) maps to home advantage: score>50 = favors home, <50 = favors away. Contribution = |score − 50| / 50. Allows per-factor gradient calculation.
🎯 Calibration
Model is calibrated if predicted 70% outcomes actually win ~70% of the time. The calibration panel shows expected vs actual win rates by confidence bucket.
